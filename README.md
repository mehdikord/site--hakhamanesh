# املاک هخامنش — پروژهٔ Next.js

تبدیل فایل HTML تحویلی به **Next.js App Router، React و TypeScript** با حفظ طراحی سرمه‌ای/طلایی، فونت وزیرمتن، تصاویر، متن‌ها، راست‌به‌چپ بودن و ترتیب بخش‌های اصلی.

این پروژه پوسته‌ای دور HTML قدیمی یا iframe نیست: هر صفحه مسیر واقعی دارد، بخش‌ها کامپوننت React هستند و محتوای صفحات در سرور رندر می‌شود. فایل اولیه فقط برای مراجعه در `reference/original.html` نگهداری شده و در اجرای سایت استفاده نمی‌شود.

## اجرای سریع

**پیشنهاد: Node.js 24 LTS**؛ فایل `.nvmrc` آماده است. اجرای نهایی روی Node 24 بررسی شده است.

```bash
npm ci
npm run setup
# فایل .env.local را مطابق .env.example تنظیم کنید.
npm run build
npm start
```

سایت روی پورت `3000` و آدرس `0.0.0.0` اجرا می‌شود. برای تغییر پورت:

```bash
PORT=4000 npm start
```

- `npm start` واقعاً `next start` را اجرا می‌کند؛ خروجی **static export نیست**.
- هیچ تنظیم `output: 'export'` و هیچ وابستگی به پوشهٔ `out` وجود ندارد.
- صفحات سایت server-rendered هستند؛ API ثبت درخواست هم به فرایند Node نیاز دارد.
- تولید فایل‌های `robots.txt` و `sitemap.xml` در build، به معنی export شدن سایت نیست.
- حالت توسعه: `npm run dev`؛ از این دستور برای سرویس production استفاده نکنید.

**راهنمای سرویس لینوکس و Nginx: [docs/deployment-fa.md](docs/deployment-fa.md)**

## مسیرهای مستقل

| مسیر                                       | محتوا                                            |
| ------------------------------------------ | ------------------------------------------------ |
| `/`                                        | خانه با تمام بخش‌های فایل اصلی                   |
| `/properties`                              | بانک املاک، فیلتر، مرتب‌سازی و نمایش بیشتر       |
| `/search`                                  | صفحهٔ مستقل جستجو؛ وضعیت فیلترها در query string |
| `/properties/hx-1042`                      | نمونهٔ جزئیات ملک؛ هر ۱۴ ملک آدرس اختصاصی دارد   |
| `/blog`                                    | مجله، جستجو و دسته‌بندی مقالات                   |
| `/blog/buying-apartment-north-tehran-1405` | نمونهٔ مقاله؛ هر ۶ مقاله آدرس اختصاصی دارد       |
| `/favorites`                               | علاقه‌مندی‌های ذخیره‌شده در مرورگر               |
| `/about`                                   | دربارهٔ مجموعه                                   |
| `/contact`                                 | تماس، نقشه و پرسش‌های متداول                     |
| `/terms`                                   | متن قوانین و حریم خصوصی فایل اصلی                |
| `/api/requests`                            | ثبت واقعی فرم‌ها؛ فقط `POST`                     |
| `/api/health`                              | بررسی زنده بودن سرویس                            |

نمونهٔ آدرس قابل اشتراک جستجو:

```text
/search?deal=sale&type=apartment&budget=35&minArea=150
```

Refresh، بازشدن در تب جدید، Back/Forward و کپی لینک جزئیات کار می‌کنند. آدرس ملک/مقالهٔ ناموجود، صفحهٔ هماهنگ با طراحی و HTTP 404 دارد.

## ساختار پروژه

```text
src/
  app/                     مسیرها، metadata، layout و APIهای سروری
  components/
    layout/                هدر، نوار بالا، فوتر و منوی موبایل
    home/                  بخش‌های جداگانهٔ خانه، جستجو، اسلایدر و محاسبه‌گر
    properties/            کارت، فیلترها، نتایج، گالری و جزئیات ملک
    blog/                  کارت، فهرست و جزئیات مقاله
    forms/                 مشاوره، تماس، بازدید، خبرنامه و وضعیت ارسال
    about/                 داستان، منشور، خط زمانی و تیم
    contact/               اطلاعات تماس و FAQ
    shared/                آیکون‌ها، دیالوگ، اعلان‌ها و ابزارهای مشترک
  data/                    ۱۴ ملک، ۶ مقاله و دیگر محتوای فایل اصلی
  lib/                     جستجو، نرمال‌سازی فارسی، اعتبارسنجی و ذخیرهٔ امن
public/
  images/                  ۵۲ فایل تصویری از همان URLهای فایل اصلی
  fonts/                   وزیرمتن محلی و مجوز فونت
reference/original.html    نسخهٔ دست‌نخوردهٔ ورودی
scripts/                  تنظیم کلید و خواندن درخواست‌ها
```

- Server Component برای ساختار و محتوای ثابت؛ Client Component برای بخش تعاملی.
- هیچ `innerHTML`، ارزیابی رشتهٔ JavaScript یا اسکریپت سراسری HTML اولیه در برنامه وجود ندارد.
- CSS اصلی حفظ شده؛ سازگاری Tailwind 4 برای حفظ line-height، رنگ‌ها، سایه‌ها و glass اضافه شده است.
- برای تغییر محتوا، `src/data` و کامپوننت مربوطه را ویرایش و مجدداً build کنید. CMS و پنل مدیریت جزو این تحویل نیست.

## فرم‌ها: ثبت واقعی، نه پیام موفقیت ساختگی

فرم‌های فایل اصلی فقط پیام موفقیت و کد تصادفی نشان می‌دادند. این نسخه تنها پس از پاسخ موفق API پیام موفقیت نشان می‌دهد:

1. اعتبارسنجی سمت سرور و پذیرش ارقام فارسی/عربی برای موبایل؛
2. بررسی مبدأ درخواست، محدودیت حجم، محدودیت نرخ و فیلد ضدربات؛
3. ثبت یک فایل رمزنگاری‌شده با AES-256-GCM برای هر درخواست در `DATA_DIR`؛
4. بازگرداندن کد پیگیری تولیدشده در سرور.

`npm run setup` کلید تصادفی را در `.env.local` می‌سازد و هرگز کلید موجود را خودکار عوض نمی‌کند. بدون کلید معتبر یا مجوز نوشتن روی `DATA_DIR`، API خطای 503 می‌دهد، نه موفقیت جعلی.

خواندن درخواست‌ها توسط مدیر سرور:

```bash
npm run requests
```

**کلید و پوشهٔ داده را جداگانه و امن پشتیبان‌گیری کنید. گم‌شدن کلید یعنی از دست رفتن امکان بازیابی درخواست‌ها.** پوشهٔ داده نباید زیر `public` باشد؛ رمزنگاری اطلاعات جای HTTPS را نمی‌گیرد.

این قابلیت فقط **ثبت درخواست** است؛ ارسال خودکار ایمیل، پیامک، تماس، تأیید قطعی نوبت، ارسال خبرنامه و لغو اشتراک به سرویس بیرونی/CRM متصل نشده‌اند. هیچ پنل مدیریت عمومی یا API خواندن اطلاعات مشتریان ایجاد نشده است. برای ارسال واقعی خبرنامه، اتصال به سرویس ایمیل و فرایند رضایت/لغو اشتراک لازم است.

## تنظیمات لازم پیش از انتشار

در `.env.local`:

```dotenv
SITE_URL=https://your-domain.example
DATA_DIR=/var/lib/hakhamanesh/requests
LEADS_ENCRYPTION_KEY=کلید_واقعی_تولیدشده_توسط_setup
TRUST_PROXY=1
```

مقدار بالا برای کلید صرفاً توضیح است؛ کلید واقعی را `npm run setup` تولید می‌کند.

- `SITE_URL` را پیش از build به دامنهٔ نهایی تغییر دهید؛ canonical، sitemap و Open Graph از آن استفاده می‌کنند.
- `TRUST_PROXY=1` فقط پشت پروکسی کنترل‌شده‌ای مانند فایل Nginx تحویلی؛ آن پروکسی باید هدرهای IP/Host را بازنویسی کند. برای اجرای مستقیم، `0` بماند.
- لینک‌های شبکهٔ اجتماعی در فایل اولیه `#` بودند. مقادیر `NEXT_PUBLIC_*_URL` را با آدرس‌های واقعی پر کرده و rebuild کنید. تا آن زمان دکمه‌ها پیام «تنظیم نشده» می‌دهند و به آدرس ساختگی هدایت نمی‌کنند.
- تنها وابستگی تصویریِ آنلاین، iframe نقشهٔ Google است. فونت، تصاویر سایت، CSS و آیکون‌ها محلی هستند.
- نقشهٔ ملک، محله را نمایش می‌دهد؛ مختصات دقیق ملک در ورودی موجود نبود.
- دکمهٔ «تور ویدیویی برج» مانند ایدهٔ فایل اولیه تصویر برج را بزرگ می‌کند؛ ویدیو/بروشور واقعی در ورودی ارائه نشده بود. برای پخش ویدیو باید فایل واقعی متصل شود.

## نسخه‌ها

نسخه‌های اصلی از برچسب پایدار `latest` رجیستری npm در تاریخ **۲۰۲۶-۱۰-۰۳** بررسی و در lockfile تثبیت شدند:

| ابزار                          | نسخه   |
| ------------------------------ | ------ |
| Next.js                        | 16.3.8 |
| React / React DOM              | 19.3.0 |
| Tailwind CSS / PostCSS adapter | 4.3.3  |
| Lucide React                   | 1.51.0 |
| Zod                            | 4.6.5  |
| Vazirmatn font package         | 5.3.0  |
| Playwright                     | 1.63.0 |
| Prettier                       | 3.9.9  |

ابزارهای TypeScript `6.0.3` و ESLint `9.39.5` بر اساس محدودیت سازگاری `eslint-config-next` انتخاب شدند: زنجیرهٔ فعلی lint هنوز peer dependency سازگار با TypeScript 7 / ESLint 10 ندارد. برای نصب قابل تکرار از `npm ci` و `package-lock.json` استفاده کنید، نه ارتقای اجباری همهٔ بسته‌ها.

دو آیکون Instagram و LinkedIn که از Lucide جدید حذف شده‌اند، با همان خطوط SVG طرح اولیه حفظ شدند.

## بررسی و آزمون

```bash
npm run check
npm run build
npm start
# در ترمینال دوم؛ نصب مرورگرها فقط برای آزمون لازم است:
npx playwright install --with-deps
npm test
```

- `check`: lint، تولید typeهای مسیر، TypeScript و unit test.
- `npm run format` / `npm run format:check`: قالب‌بندی خوانای کد.
- تست مرورگر روی **production server** اجرا می‌شود، نه dev server.
- جزئیات عرض‌ها، مرورگرها و آزمون‌ها در [گزارش QA](docs/qa-fa.md) است.
- تست فرم‌ها دادهٔ آزمایشی ثبت می‌کند؛ روی محیط آزمایش اجرا شود، نه سرور عمومی دارای مشتری.

## حدود محتوای تحویلی

تمام ۱۴ ملک و ۶ مقاله از ورودی آمده‌اند. اعدادی مثل «۲۱۴ ملک فعال»، آمار معاملات، مجوزها، تضمین‌ها، تعرفهٔ کمیسیون، مشخصات فنی مشترک و متن حریم خصوصی **محتوای خود فایل اولیه‌اند و صحت حقوقی/تجاری آن‌ها در این تبدیل تأیید نشده است**. برای حفظ طراحی/محتوا بازنویسی نشده‌اند؛ قبل از انتشار عمومی باید با وضعیت واقعی کسب‌وکار، محل میزبانی، سیاست نگهداری/حذف داده و مجوز تصاویر تطبیق داده شوند.

فهرست منابع تصاویر در `docs/asset-sources.json` و تغییرات فنی در [docs/migration-fa.md](docs/migration-fa.md) آمده است.
