# گزارش بررسی نهایی

تاریخ: **۲۰۲۶-۱۰-۰۳** — محیط: Linux، Node.js **24.21.0**، اجرای **production با `npm start`**.

## نتیجهٔ ساخت و بررسی کد

| بررسی                            | نتیجه                                       |
| -------------------------------- | ------------------------------------------- |
| نصب تمیز با `npm ci` از lockfile | موفق                                        |
| `npm run lint`                   | بدون خطا/هشدار کد                           |
| `next typegen` و `tsc --noEmit`  | موفق                                        |
| `npm run build`                  | موفق؛ صفحات سایت SSR و API از نوع Node.js   |

| آزمون واحد                       | ۹ سناریو موفق                               |
| آزمون مرورگر                     | آخرین نتیجهٔ هر ۳۴ سناریو موفق              |
| `npm audit --omit=dev`           | صفر آسیب‌پذیری گزارش‌شده در این بررسی       |
| منابع تصاویر                     | ۵۲ فایل محلی معتبر، بدون ارجاع محلی ناموجود |

گزارش ماشین‌خوان: [`qa-summary.json`](qa-summary.json). گزارش امنیت به وابستگی‌های **production** محدود است و تضمین امنیت کامل محصول محسوب نمی‌شود.

## ماتریس واکنش‌گرایی

یازده مسیر شامل خانه، بانک املاک، جستجوی بودجه‌دار، جزئیات ملک فروش و اجاره، مجله، مقاله، درباره، تماس، قوانین و علاقه‌مندی‌ها بررسی شدند:

- **Chromium:** عرض‌های ۳۲۰، ۳۶۰، ۳۹۰، ۴۸۰، ۶۴۰، ۷۶۸، ۱۰۲۴، ۱۲۸۰، ۱۴۴۰ و ۱۹۲۰ پیکسل؛
- **Firefox:** عرض‌های ۳۹۰، ۷۶۸ و ۱۴۴۰؛
- **WebKit:** عرض‌های ۳۹۰، ۷۶۸ و ۱۴۴۰.

این یعنی **۱۷۶ ترکیب مسیر/عرض/موتور** در ماتریس، علاوه بر آزمون‌های تعاملی. سرریز افقیِ کنترل‌ها/محتوا و نمایش عنوان اصلی بررسی شد. marquee عمداً متحرک و clip شده و از تشخیص سرریز عمدی مستثنا است.

این آزمون‌ها viewport و موتور مرورگر را در لینوکس شبیه‌سازی می‌کنند؛ به معنی آزمایش روی تمام گوشی‌های فیزیکی یا تمام نسخه‌های قدیمی Safari/Android نیستند. iframe خارجی نقشه در آزمون خودکار جایگزین خالی شده تا وابستگی شبکه‌ای خارج از کنترل پروژه وارد نتیجهٔ layout نشود.

- ذخیره، refresh، حذف و همگام‌سازی علاقه‌مندی‌ها و تحمل localStorage نامعتبر؛
- تغییر تصویر اصلی، lightbox، کنترل Tab/Escape و بازگرداندن focus؛
- منوی موبایل در عرض ۳۲۰px و بازکردن فرم مشاوره از آن؛
- دسته‌بندی، جستجو و لینک جزئیات مقاله؛

- محاسبهٔ اقساط با واحد صحیح و آزمون فرمول بدون سود؛
- باز/بسته‌شدن FAQ؛
- 404 واقعی برای ملک/مقاله/مسیر ناموجود؛
- وجود عنوان و بدنهٔ مقاله/ملک در HTML با JavaScript غیرفعال؛
- ثبت تماس، مشاوره، بازدید و عضویت در خبرنامه از مسیر API؛
- شمارهٔ فارسی، رضایت‌نامه، خطای اعتبارسنجی، درخواست بزرگ و مبدأ غیرمجاز؛

- بازیابی فایل‌های رمزنگاری‌شدهٔ آزمایشی با کلید متناظر.

## چرخهٔ نهایی آزمون

گزارش عدد ۳۴، **آخرین نتیجهٔ هر سناریو** در دور کامل و بازآزمون موارد مربوط است، نه ادعای سبز بودن تمام اجراهای اولیه. در اجرای موازی روی VM کم‌منبع، یک تست قبل از پایان hydration فیلد را پر می‌کرد و یک اجرای WebKit با کمبود زمان روبه‌رو شد. انتظار آماده‌شدن UI به تست افزوده و اجرای مرورگرها به یک worker محدود شد؛ چهار سناریوی مربوط مجدداً اجرا و همگی موفق شدند. بین این دور کامل و بازآزمون، کد برنامه تغییر نکرد.

در مرحلهٔ پیشین، خطای درخواست prefetch لغوشدهٔ WebKit با سیاست صریح `prefetch={false}` برای لینک‌ها رفع شد. ناوبری Next.js و لینک واقعی همچنان فعال است. جزئیات آمار هر دور در JSON ثبت شده است.

## موارد خارج از دامنهٔ این آزمون

نصب روی سرور واقعی شما و اجرای systemd/Nginx، اعتبار گواهی TLS دامنهٔ نهایی، صحت اطلاعات تجاری/حقوقی محتوای اولیه، ارسال ایمیل/پیامک، اتصال CRM، بار همزمان production و تست نفوذ تخصصی. این موارد به تنظیمات و سرویس‌های واقعی مجموعه نیاز دارند.
